# StudyFlow – Student Task Manager

StudyFlow ist eine responsive Webanwendung, mit der Studierende ihre Aufgaben organisieren und ihre Lernziele im Blick behalten können.

## Live Demo

👉 **[StudyFlow online ansehen](https://katoyzu.github.io/studyflow/)**

## Funktionen

- Aufgaben hinzufügen
- Aufgaben bearbeiten und löschen
- Aufgaben als erledigt markieren
- Aufgaben nach Status filtern
- Prioritäten festlegen: niedrig, mittel oder hoch
- Fälligkeitsdaten hinzufügen
- Statistiken über alle, erledigten und offenen Aufgaben anzeigen
- Aufgaben mit Local Storage im Browser speichern
- Responsives Design für Computer, Tablets und Smartphones

## Verwendete Technologien

- **HTML5** – Struktur der Anwendung
- **CSS3** – Design und responsives Layout
- **JavaScript** – Interaktive Funktionen und Aufgabenverwaltung
- **Local Storage** – Speicherung der Aufgaben im Browser
- **Git und GitHub** – Versionsverwaltung und Hosting mit GitHub Pages

## Installation

1. Dieses Repository herunterladen oder klonen.
2. Die Datei `index.html` im Browser öffnen.
3. Aufgaben erstellen und StudyFlow ausprobieren.
